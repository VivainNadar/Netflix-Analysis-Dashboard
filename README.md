# Netflix-Analysis-Dashboard

Project Purpose:
The purpose of this project is to:
Practice data analytics and visualization skills using Power BI
Analyze Netflix content trends and patterns
Create an interactive dashboard for better storytelling with data
Improve understanding of data cleaning, transformation, and dashboard design
Build a portfolio-ready project for internships and job opportunities in data analytics

Tech Stack Used
1.Power BI
2.Power Query
3.DAX (Data Analysis Expressions)
4.Data Visualization

Data Source
link:https://www.kaggle.com/datasets/paramvir705/netflix-dataset

Dashboard Features
1.Interactive Filters:
The dashboard includes dynamic slicers for:

Content Type (Movie / TV Show)
Country
Rating

These filters allow users to explore the data interactively and analyze specific categories.

2.Key Performance Indicators (KPIs)

The dashboard displays important summary metrics such as:

Total Shows
Total Directors
Total Countries
Total Actors

These KPI cards provide a quick overview of the Netflix dataset.

Visualizations Included
1. Movies vs TV Shows Distribution
Donut chart comparing the percentage of Movies and TV Shows
Helps understand the dominant type of content available on Netflix
2. Content Added Each Year
Line/Area chart showing yearly growth of Netflix content
Highlights the increase in content over time
3. Top 5 Actors
Bar chart displaying actors with the highest number of appearances
Helps identify frequently featured actors
4. Top 8 Directors
Bar chart displaying directors with the highest content count
Useful for identifying top contributors on the platform

Design Highlights
Netflix-inspired red and black theme
Clean and modern dashboard layout
Interactive and user-friendly design
Proper alignment and visual hierarchy
Dynamic filtering experience
